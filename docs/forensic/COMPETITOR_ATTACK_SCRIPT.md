# Competitor Attack Script

Statements a salesperson for Gemini or ChatGPT can make **truthfully** to a Taskkorb user. If the sentence is true, it is a gap.

Confidence: STRONG unless marked.

## Gemini app salesperson

1. “You already have a Google account. You will not create an API key for a talking ball.”
2. “Tap Live. You do not hold a button to be allowed to think.” ([Gemini Live](https://gemini.google/overview/gemini-live/))
3. “Your conversation stays in one thread. Theirs dies when you clear the tab or hit 2400 characters.”
4. “I can look at your camera or your screen while we talk.” ([Gemini Apps Help](https://support.google.com/gemini/answer/15274899))
5. “I can check Calendar, Gmail, Maps. Their orb cannot do anything except spend quota.” ([Gemini Live](https://gemini.google/overview/gemini-live/))
6. “You can change my voice. They shipped one name: Orus.”
7. “Their public link already died with Cloudflare 1033. I am in the App Store.”
8. “If they ‘hosted’ a key for you, everyone with the preview password shares that key’s quota.”

## ChatGPT salesperson

1. “Tap the waveform. Free tier includes GPT-Live mini.” ([Engadget](https://www.engadget.com/2230975/how-to-use-chatgpt-voice-mode/), [Techish](https://jjtechish.substack.com/p/how-to-use-chatgpt-voice))
2. “We listen while we talk. They make you hold Talk like a walkie-talkie.” ([andrew.ooo](https://andrew.ooo/answers/gpt-live-vs-advanced-voice-vs-gemini-live-full-duplex-july-2026/))
3. “Voice keeps going if you lock the phone. Their tab suspends the animation and drops the socket.” ([Engadget](https://www.engadget.com/2230975/how-to-use-chatgpt-voice-mode/))
4. “We have a desktop app and a website your mom already uses.”
5. “They are a Gemini Live demo with a shader. You do not need a third app for that.”

## ElevenLabs / custom-agent salesperson (to an operator)

1. “Your API key never enters the browser. You mint a signed URL behind your own login.” ([ElevenLabs Next.js](https://elevenlabs.io/docs/eleven-agents/guides/quickstarts/next-js))
2. “We have a session SDK, not an 800-line Lit file that owns the socket, the mic, and the CSS.”
3. “You can attach client tools. Their orb has no tools.”
4. “They still offer a pasted long-lived Gemini key as the default path.”

## What they cannot truthfully say

- “Taskkorb stores your Gemini key in sessionStorage.” — **OUTDATED**. Memory-only now.
- “They play only the first audio part.” — **OUTDATED**. All parts are scheduled.
- “There is no way to change the key.” — **OUTDATED**.
- “The talk button has no label.” — **OUTDATED**.
- “They have no CSP / no privacy sentence.” — **OUTDATED** (partial).

Attack the current product, not last week’s demo.

## Ranked by kill-shot

1. No account / BYO key (activation)
2. No durable host (distribution)
3. No history (retention)
4. Hold-to-talk vs one-tap live (UX)
5. No tools (utility)
6. Orb is chrome (positioning)
