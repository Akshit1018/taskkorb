## How a competitor beats this in one sentence

Ship Gemini or ChatGPT and never ask for an API key.

## Does each gap matter?

- Account/no key: **yes**, or there is no product.
- History: **yes**, or Taskkorb is a toy.
- Camera: **no** unless the vision changes.
- Orb visual: **only if** it becomes the identity, not wallpaper.
